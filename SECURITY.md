# Security policy

MediCafe V1 is an early public planning repository. Do not use public issues, pull requests, or attachments to report a suspected vulnerability, credential exposure, or accidental protected health information.

Use [GitHub private vulnerability reporting](https://github.com/katanada2/MediCafe-v1/security/advisories/new) when enabled. If that channel is unavailable, open an issue asking only for a private reporting route, without vulnerability details, credentials, or personal information.

Reports should include the affected revision or file, a concise description of the issue, reproduction steps that use synthetic data, and the impact you observed. Redact tokens, personal information, patient information, and private infrastructure details from every report.

This policy does not claim that the planned application is secure, compliant, or ready for production. It describes how to handle reports about the public repository while the design is being developed.
