# Policy owner and routes

Astra retains architecture and milestone acceptance. The coordinator records
accepted scope and owns publication/coordination. An explicitly assigned sole
writer maintains a shared implementation seam.

- Developer verification authority: [change-surface control](../CHANGE_SURFACE_CONTROL.md).
- Machine routing authority: [static catalog](../../tools/workflow_boundary_registry.json).
- Governing-guidance review authority: [canonical coherence procedure](../../tools/CODEX_SCAFFOLDING_COHERENCE_REVIEW.md).
- Product/business authority: [charter](../architecture/CHARTER.md) and admitted cards.

AGENTS and skills route to these authorities; they do not introduce another
verification registry or override implementation admission. No private V0
guidance or operational evidence is imported into this public index.
