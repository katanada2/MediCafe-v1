# Canonical scaffolding coherence review

This is the V1 public-native governing-guidance procedure, not a copy of private
V0 governance. Read [the owner index](../docs/agent-guidance/README.md) and the
complete [verification policy](../docs/CHANGE_SURFACE_CONTROL.md). Product meaning
stays with the charter/cards; the JSON catalog alone owns machine routing.

1. Select every changed path with the policy's runner/selector. Follow each
   boundary-scan decision; unknown/malformed selection is a review gap, not a pass.
2. Locate the actual authority for each changed instruction. Update that source
   only and leave consumers as concise routes. Do not synchronize copied passages.
3. Trace downstream agent/test/CI behavior. Check static references and planned
   versus implemented contracts; execute the selected tooling checks. Feature
   execution and browser evidence remain separate from static validation.
4. Review duplication, obsolete guidance, privacy, ownership and CI cost. Do not
   import private policy or introduce a runtime evidence registry. Advisory
   graph tools may identify drift but cannot generate/replace instructions.
5. Include these eight findings in the final review/handoff:

   - Canonical source: named authority for each policy and machine route.
   - Propagation map: authority to consumers, selector and actual tests/CI.
   - Boundary impact: changed evidence/state/wording and fail-closed cases.
   - Agent behavior delta: exactly what an agent now selects, runs or stops on.
   - Duplication/conflict check: no second authority or private-policy copy.
   - Retirement check: obsolete routes/copies removed or explicitly absent.
   - CI efficiency check: one lightweight tooling lane, no duplicate full suite.
   - Acceptance check: exact executed/unrun tests, runtime and remaining gates.

Stop for unreviewed policy meaning, ownership change, unsafe/private inputs or
missing required feature evidence. A selector/checklist success never grants
business permission, production qualification or O1 runtime admission.
